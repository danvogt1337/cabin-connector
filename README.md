# Cabin Connector

Home-Assistant-Add-on, das ein Home Assistant sicher mit dem [Cabinmanager](https://cabinmanager.de) verbindet –
ohne offene Ports ins Internet, ohne Tunnel.

## Installation

1. In Home Assistant: **Einstellungen → Add-ons → Add-on Store → ⋮ → Repositories**
2. Diese Adresse eintragen: `https://github.com/danvogt1337/cabin-connector`
3. „Cabin Connector“ installieren und starten, dann die Oberfläche des Add-ons öffnen und den Code im Cabinmanager unter
   **Einstellungen → Gateways** eingeben.

Mehr dazu in [cabin_connector/DOCS.md](cabin_connector/DOCS.md).
